## ufolens.com — многоезична платформа с възможност за търсене в архива на PURSUE UAP

**На живо:** https://www.ufolens.com · **API:** https://www.ufolens.com/api/v1 · **Изходен архив:** https://www.war.gov/ufo

`ufolens.com` препубликува архива **PURSUE** на Военния департамент на САЩ с разсекретени записи за UAP / UFO като платформа за знания: търсене в пълен текст, машинен превод в целия корпус, изследване на карта + хронология и публичен JSON API. Изходните документи са произведения на федералното правителство на САЩ и в рамките на САЩ са обществено достояние ([17 U.S.C. §105](https://www.copyright.gov/title17/92chap1.html#105)). Този проект **не е свързан с правителството на САЩ**, не използва официални отличителни знаци и никога не премахва редакции.

### Архитектура

```
Локална машина (Apple Silicon, жилищен IP адрес)   Edge мрежа
─────────────────────────────────────────           ─────────────────────────
pipeline/  (Python 3.10, ядро само със stdlib)      worker/  (TypeScript, Hono.js)
  fetch → OCR → translate → publish  (само напред)     /{lang}/...   страници
  OCR: енджин с отворен код (Tesseract CLI резерва)    /api/v1/...   публичен API
  translate / NER: локален LLM (Gemma чрез Ollama)     /admin        операторска конзола
  state: SQLite манифест                             подкрепен от: edge SQL DB, обектно
        │                                              хранилище (изходни PDF), KV кеш
        └── публикува пакет: SQL + манифест на активи + списък за изчистване на кеша ──┘
```

- **Нулев разход за облачен AI на документ.** OCR и преводът се изпълняват локално; машината на състоянията „само напред“ (`discovered → downloaded → ocr_done → translated → published`) гарантира, че нито един документ не се обработва повторно, освен ако не се е променил.
- **Ядрото на Pipeline няма зависимости от трети страни** — модулите за парсиране / манифест / делта се изпълняват и тестват на чист Python без нищо инсталирано с pip; етапите на OCR/превод деградират плавно, когато опционалните пакети липсват.
- **Edge сайтът** прилага стриктни заглавки за сигурност + CSP (без `unsafe-inline`; вграденият JSON-LD е с sha256-пин), договаряне на език чрез `Accept-Language` + съпоставяне по държава, 30-дневен KV кеш за страници и ежедневно cron задание за поддръжка.
- **Инкрементални актуализации:** детектор на разлики (delta detector) сравнява индекса на източника и подава само промените обратно в pipeline.

### За разработчици

Публичният API на https://www.ufolens.com/api/v1 връща документи и метаданни като JSON. Анонимният достъп е с ограничен брой заявки; поискайте ключ за нива за изследователи/разработчици. Вижте секцията API на сайта за крайни точки и лимити.

### Статус

Кодът е завършен; сайтът е внедрен на https://www.ufolens.com. Производствената база данни се попълва чрез изпълнение на офлайн pipeline и публикуване на пакета напред (`cli_publish run --remote`). Пълната проектна документация се намира в `docs/20260511/`.
