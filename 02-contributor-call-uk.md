## Співпраця з ufolens.com

[ufolens.com](https://www.ufolens.com) перетворює [архів PURSUE UAP](https://www.war.gov/ufo) Військового департаменту США на пошукову, багатомовну платформу з [публічним API](https://www.ufolens.com/api/v1). Проект складається з двох половин — локального конвеєра обробки на Python (`pipeline/`) та edge-додатку на TypeScript/Hono (`worker/`) — які зустрічаються в одному інтерфейсі: опублікованому пакеті SQL + асети.

Вам не потрібні жодні хмарні облікові дані, щоб долучитися. Основні модулі конвеєра використовують лише стандартну бібліотеку, а тести для Worker запускаються з використанням сховища в пам'яті.

### Налаштування

```bash
# pipeline
python3 -m pytest pipeline/tests/          # should be all green, no pip install needed

# worker
cd worker && npm install
npm run typecheck && npm test              # tsc --noEmit + vitest
npm run dev                                # localhost:8787
```

### Де допомога найкорисніша

**i18n / локалізація** — `worker/src/i18n/ui-strings.json` є джерелом рядків інтерфейсу. Перевірка будь-якої неанглійської локалі носієм мови є надзвичайно цінною: виявлення незграбного машинного перекладу, виправлення проблем з RTL/макетом, покращення крайніх випадків узгодження мови.

**Якість OCR** — краща попередня обробка старих машинописних сканів перед OCR; система оцінки для порівняння рушія з відкритим кодом з резервним Tesseract на зразках сторінок.

**Доступність** — аудит відрендерених сторінок (`worker/src/render/`) на відповідність WCAG; CSP є суворим (без `unsafe-inline`), тому рішення мають працювати в його межах.

**Ергономіка API** — `worker/src/routes/` — пагінація, фільтрація, опис OpenAPI, приклади клієнтів.

**Надійність конвеєра** — більш плавні шляхи деградації, краще звітування про прогрес, крайні випадки виявлення дельт (`pipeline/lib/delta.py`).

**Документація** — `docs/20260511/` (繁體中文; `00-*` є індексом). Переклади проектної документації на англійську мову вітаються.

### Основні правила

- Усі шляхи відносні — проект має бути портативним між машинами. Жодних жорстко закодованих абсолютних шляхів.
- Не додавайте залежності pip до *основного* модуля конвеєра. Опціональні етапи можуть використовувати опціональні пакети і повинні плавно деградувати без них.
- Не послаблюйте машину станів "тільки вперед" — це стеля витрат.
- Не додавайте офіційні знаки розрізнення уряду США і не додавайте нічого, що скасовує редагування джерела.
- Зміни схеми D1 торкаються **двох** файлів: `pipeline/lib/manifest_schema.sql` та `db/schema.sql`.
- Новий код має супроводжуватися тестами. Повідомлення комітів у стилі Conventional Commits.
