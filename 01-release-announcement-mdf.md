## ufolens.com — PURSUE UAP архивонди лангс вешендемань ды лама кельсэ платформа

**Эряй:** https://www.ufolens.com · **API:** https://www.ufolens.com/api/v1 · **Источник-архив:** https://www.war.gov/ufo

`ufolens.com` одста нолды Американь Сотксонь Ойнань Департаментть **PURSUE** архивонц секретонь луфтум UAP / UFO записнень содамошинь платформакс: пяшксе текстсэ вешендема, машинань ётафтома всем корпусти, картань + пингонь линиянь исследования, ды публичнай JSON API. Источник-документтне тя Американь Сотксонь федеральнай правительствань тефне и Американь Сотксонь потмоса общественнай достояни ([17 U.S.C. §105](https://www.copyright.gov/title17/92chap1.html#105)). Тя проектсь **аф сотф Американь Сотксонь правительствать мархта**, аф мольфти официальнай insignia, и мзярдовок аф мърдафтови редакциетне.

### Архитектурась

```
Локальнай машина (Apple Silicon, эряма вастонь IP) Краень сеть
───────────────────────────────────────── ─────────────────────────
pipeline/ (Python 3.10, stdlib-only core) worker/ (TypeScript, Hono.js)
  fetch → OCR → translate → publish (аньцек инголи) /{lang}/... лопат
  OCR: панжада кодонь движок (Tesseract CLI резерв) /api/v1/... публичнай API
  translate / NER: местной LLM (Gemma Ollama вельде) /admin операторонь консоль
  ащемась: SQLite манифест backed by: краень SQL DB, объектнай
        │ хранилище (источник PDF), KV кэш
        └── нолды пакет: SQL + актив манифест + кэш-чистамонь список ──┘
```

- **Ноль касома облачнай-AI-нь эрь документти.** OCR ды ётафтомась тиевихть локальна; аньцек инголи моли машинань состояния (`discovered → downloaded → ocr_done → translated → published`) гарантируй, што документсь аф обработави одста, если сон аф полафтовсь.
- **Pipeline-нь кучкась колмоце пяльксонь зависимостень апак** — парсинг / манифест / дельта модульхне работайхть ды тестируевихть таза Python-ца, коса аш мезе pip-са установлена; OCR/ётафтомань стадиятне плавна деградируйхть, кда необязательнай пакеттне аш.
- **Краень сайтсь** применяй строгай безопасностьть заголовкат + CSP (аш `unsafe-inline`; инлайн JSON-LD sha256-са кемокстаф), келень переговорт `Accept-Language` + странанень карта вельде, 30-шинь KV лопань кэш, ды ежедневнай хозяйствань cron.
- **Шаг за шагом одкстоптомат:** дельта-детекторсь муси разницатнень источниконь индексть потмоса и максы аньцек полафтоматнень трубопроводс.

### Разработчикненди

Публичнай API https://www.ufolens.com/api/v1 адрести максы документт ды метаданные JSON формацса. Анонимнай доступсь ограничен скоростть коряс; вешентт ключ исследовательскяй/разработчикскяй уровеньди. Ваннтт API-нь разделть сайтса конечнай точкатнень ды лимиттнень коряс.
