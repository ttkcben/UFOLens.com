## Допринос пројекту ufolens.com

[ufolens.com](https://www.ufolens.com) претвара [PURSUE UAP архиву](https://www.war.gov/ufo) америчког Министарства рата у претраживу, вишејезичну платформу са [јавним API-јем](https://www.ufolens.com/api/v1). Састоји се из две половине — локалног Python pipeline-а за унос података (`pipeline/`) и TypeScript/Hono edge апликације (`worker/`) — које се сусрећу на једном интерфејсу: објављеном SQL + пакету ресурса.

Нису вам потребни никакви cloud акредитиви да бисте допринели. Основни модули pipeline-а користе само стандардну библиотеку, а тестови за Worker се извршавају над меморијским складиштем.

### Подешавање

```bash
# pipeline
python3 -m pytest pipeline/tests/          # требало би да све прође, није потребна pip инсталација

# worker
cd worker && npm install
npm run typecheck && npm test              # tsc --noEmit + vitest
npm run dev                                # localhost:8787
```

### Где је помоћ најкориснија

**i18n / локализација** — `worker/src/i18n/ui-strings.json` је извор string-ова за кориснички интерфејс. Преглед било ког не-енглеског језичког подручја од стране изворног говорника је веома вредан: ухватите незграпне машинске преводе, поправите проблеме са RTL/распоредом, побољшајте ивичне случајеве преговарања о језику.

**Квалитет OCR-а** — боља пре-обрада старих скенираних докумената откуцаних писаћом машином пре OCR-а; систем за процену који пореди open-source машину са Tesseract резервном опцијом на узорцима страница.

**Приступачност** — ревизија рендерованих страница (`worker/src/render/`) у складу са WCAG; CSP је строг (без `unsafe-inline`), тако да решења морају радити унутар тих ограничења.

**Ергономија API-ја** — `worker/src/routes/` — пагинација, филтрирање, OpenAPI опис, примери клијената.

**Робусност pipeline-а** — више путања за грациозну деградацију, боље извештавање о напретку, ивични случајеви код детекције промена (`pipeline/lib/delta.py`).

**Документација** — `docs/20260511/` (繁體中文; `00-*` је индекс). Преводи пројектне документације на енглески су добродошли.

### Основна правила

- Све путање су релативне — пројекат мора бити преносив између машина. Нема хардкодованих апсолутних путања.
- Немојте додавати pip зависност у *основни* модул pipeline-а. Опционе фазе могу користити опционе пакете и морају грациозно деградирати без њих.
- Немојте слабити машину стања која иде само унапред — то је горња граница трошкова.
- Немојте уводити званичне ознаке владе САД, и немојте додавати ништа што уклања редакције из извора.
- Промене на D1 шеми утичу на **два** фајла: `pipeline/lib/manifest_schema.sql` и `db/schema.sql`.
- Тестови уз нови код. Поруке у commit-овима у складу са Conventional Commits.
