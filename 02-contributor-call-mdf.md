## uvolens.com-с лездома

[ufolens.com](https://www.ufolens.com) полафтондсы Американь Сотксонь Ойнань Департаментть [PURSUE UAP архивонц](https://www.war.gov/ufo) вешендемань, лама кельсэ платформакс [публичнай API-ть](https://www.ufolens.com/api/v1) мархта. Сон кафта пялькста — локальнай Python-онь приёмнай трубопровод (`pipeline/`) ды TypeScript/Hono-нь краень приложения (`worker/`) — конат васьфтихть фкя интерфейсса: нолдам SQL + активнень пакет.

Тейнтть аф эрявихть облачнай учетнай записть, штоба лездомс. Трубопроводонь основной модульхне stdlib-only ды Worker-нь тесттне работайхть тевса ащи хранилищать каршес.

### Аноклама

```bash
# pipeline
python3 -m pytest pipeline/tests/ # должен быть все зеленым, без установки pip

# worker
cd worker && npm install
npm run typecheck && npm test # tsc --noEmit + vitest
npm run dev # localhost:8787
```

### Коса лездомась сембода эрявикс

**i18n / локализация** — `worker/src/i18n/ui-strings.json` тя UI-нь валхнень источник. Родной кельсэ корхтайхнень эзда любой аф-английскяй локальть проверкась пяк оцю сатфкс: мумс неудобнай машинань ётафтомат, петнемс RTL/макетонь проблемат, улучшамс келень переговоронь краень случат.

**OCR-нь качесь** — сире машинописнай скаттнень лутче предварительнай обработкасна OCR-да инголе; оценочнай система, кона сравнияй панжада кодонь движокти Tesseract-нь резервонц мархта примернай лопатнень лангса.

**Доступность** — аудитондамс нолдам лопатнень (`worker/src/render/`) WCAG-ти каршес; CSP-сь строгай (аш `unsafe-inline`), сяс решениетне должент работамс тя рамкать потмоса.

**API-нь эргономикась** — `worker/src/routes/` — лопань вельде навигация, фильтрация, OpenAPI-нь описания, примеронь клиенттне.

**Трубопроводонь кемешись** — сяда лама плавной деградациянь кит, лутче прогрессонь отчётт, дельта-обнаружениянь краень случат (`pipeline/lib/delta.py`).

**Документтне** — `docs/20260511/` (繁體中文; `00-*` тя индекссь). Проектнай документтнень англань кельс ётафтомасна приветствуеви.

### Основной правилатне

- Сембе китне относительнайхть — проектсь должен быть портативнай машинатнень ёткса. Аш кемокстаф абсолютнай кит.
- Афольхть лиядоза pip-зависимость трубопроводонь *основной* модульс. Необязательнай этаттне могёт мольфтемс необязательнай пакетт, и должент плавна деградировать синь апак.
- Афольхть лиядоза ослаблена аньцек инголи моли состояниянь машинась — тя ценонь потолоксь.
- Афольхть лиядоза тийф официальнай Американь Сотксонь правительствань insignia, и афольхть лиядоза тийф мезевок, мезе мърдафтсы источниконь редакциетнень.
- D1-нь схемань полафтоматне касайхть **кафта** файлда: `pipeline/lib/manifest_schema.sql` ды `db/schema.sql`.
- Од кодонь тесттне. Conventional-commit-коряс сообщениятне.
