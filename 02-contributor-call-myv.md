## ufolens.com-с лездамо

[ufolens.com](https://www.ufolens.com) полавтосы АВШ-нь Военной Департаментэнь [PURSUE UAP архивенть](https://www.war.gov/ufo) вешневиця, ламо кельсэ платформас, конань ули [публичной API](https://www.ufolens.com/api/v1). Те кавто пелькст — локальной Python-нь `pipeline/` ды TypeScript/Hono `worker/` — сынь вастовить вейке интерфейссэ: публикавозь SQL + активень пакет.

Тонть эряви кодамояк облачной учётной записть, штобу лездамс. Трубопроводонь ядрань модультне — stdlib-only ды Worker-нь тесттне теевить in-memory хранениясо.

### Настройка

```bash
# pipeline
python3 -m pytest pipeline/tests/          # эряви улемс весе пиже, pip-нь установка арась

# worker
cd worker && npm install
npm run typecheck && npm test              # tsc --noEmit + vitest
npm run dev                                # localhost:8787
```

### Косо лезксэсь пек эряви

**i18n / локализация** — `worker/src/i18n/ui-strings.json` те UI-нь валморонь источникесь. Эрьва аволь англань келень локалень эряза кельсэ кортыцянть проверкась пек питнев. Кундадо апаро машинань ютавтоматнень, витнеде RTL/макетонь проблематнень, паролгавтодо келень коряс переговоронь случайтнень.

**OCR-нь качества** — сыре печатной сканонь паролгавтома OCR-до икеле; сравнительной система, кона сравния панжадо источнике марто движоконть Tesseract-нь запас марто выборкань лопатнесэ.

**Доступность** — аудитороводо теезь лопатнень (`worker/src/render/`) WCAG-нь коряс; CSP-сь строгой (арась `unsafe-inline`), секскак речениятне эрявить важодемс тосо.

**API-нь эргономика** — `worker/src/routes/` — пагинация, фильтрация, OpenAPI-нь описания, примеронь клиентть.

**Трубопроводонь надёжность** — седе ламо вадрясто важодемань кить, седе паро прогрессэнь пачтямо, дельта-детектированиянь случайт (`pipeline/lib/delta.py`).

**Документт** — `docs/20260511/` (繁體中文; `00-*` те индексэсь). Дизайнень документтнэнь англань кельс ютавтомась кантсть.

### Лувт

- Весе китне относительнойть — проектэнть эряви улемс портативной эрьва машинань туртов. Арасть косояк абсолютной кить.
- Апак путо pip-зависимость трубопроводонь *ядра* модулентень. Опциональной этаптнэ нолдыть тевс опциональной пакетть ды эрявить вадрясто важодемс сынст апак уле.
- Апак наксавто ансяк икелев молиця состояниянь машинань — те питнень верьце песь.

- D1-нь схеманть полавтомась токави **кавто** файлатнес: `pipeline/lib/manifest_schema.sql` ды `db/schema.sql`.
