## ufolens.com — ламо кельсэ, вешневиця платформа PURSUE UAP архивентень

**Эрямосо:** https://www.ufolens.com · **API:** https://www.ufolens.com/api/v1 · **Источникень архив:** https://www.war.gov/ufo

`ufolens.com` одс публикави АВШ-нь Военной Департаментэнь **PURSUE** архивэнть явстазь UAP / UFO записень содамочинь платформакс: пешксе текстсэ вешнема, машинань ютавтома весе корпуска, карта + шкань коряс ванома, ды публичной JSON API. Источникень документтэсь — те АВШ-нь федеральной правительствань тевть ды АВШ-со сынь публичной достояниясо ([17 U.S.C. §105](https://www.copyright.gov/title17/92chap1.html#105)). Те проектэсь **АВШ-нь правительстванть марто а ашти сюлмавозь**, а нолды тевс официальной тешксэть ды зярдояк а велявты редакциятнень.

### Архитектура

```
Локальной машина (Apple Silicon, эрямонь IP)         Edge-сетка
─────────────────────────────────────────           ─────────────────────────
pipeline/  (Python 3.10, stdlib-only core)           worker/  (TypeScript, Hono.js)
  саемс → OCR → ютавтомс → публикавомс (ансяк икелев)   /{lang}/...   лопат
  OCR: панжадо источнике марто движок (Tesseract CLI запас) /api/v1/...   публичной API
  ютавтомс / NER: локальной LLM (Gemma Ollama вельде)        /admin        операторонь консоль
  состояния: SQLite манифест                           теезь: edge SQL DB, объектонь
        │                                              хранилища (источникень PDF-ть), KV кэш
        └── публикави пакет: SQL + активень манифест + кэшень ваньскавтомань списка ──┘
```

- **Ноль облачной-AI питне эрьва документс.** OCR ды ютавтома теевить локально; ансяк икелев молиця состояниянь машинась (`арасезь → саезь → ocr_теезь → ютавтозь → публикавозь`) гарантируе, што вейкеяк документ а карми одс теевеме, бути сон а полавтови.
- **Трубопроводонь ядрасонть арасть колмоце пельде зависимостть** — парсингень / манифестэнь / дельтань модультне роботыть ды тестировить ванькс Python-со, косо арасть кодамояк pip-установочной пакетть; OCR/ютавтомань этаптне вадрясто важодить, зярдо арасть опциональной пакетть.
- **Edge-сайт** нолды тевс строгой безопасностьянь заголовкат + CSP (арась `unsafe-inline`; встроенной JSON-LD sha256-пирязь), келень коряс переговорт `Accept-Language` + масторонь коряс картань теема вельде, 30-чинь KV лопань кэш ды эрьва чинь таркань ваньскавтомань cron.
- **Incremental-ной одкстомтомат:** дельтань детектор дифференцируе источникеэнь индексэнть ды максни ансяк полавтоматнень мекев трубопроводонтень.

### Разработчиктненень

https://www.ufolens.com/api/v1-сэ публичной API-сь максни документть ды метаданнойть JSON-со. Анонимной доступтнэнь ули лимит; вешеде ключ исследователень/разработчиктнень туртов. Ванодо сайтонь API-нь разделенть конечной тоскань ды лимитнень коряс.
