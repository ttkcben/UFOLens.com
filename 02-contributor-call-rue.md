## Приспевкы до ufolens.com

[ufolens.com](https://www.ufolens.com) перетворює [архів PURSUE UAP](https://www.war.gov/ufo) Міністерства обороны США на выгледовательну, многоязычну платформу з [публичным API](https://www.ufolens.com/api/v1). Складать ся з двох половин — локалного пайплайну на затягованя на Python (`pipeline/`) і edge аплікації на TypeScript/Hono (`worker/`) — што ся стрічають на єднім інтерфейсі: публикованім пакетї SQL + активів.

Не потребуєте жадных хмаровых повіреня про приспевкы. Основны модулі пайплайну суть лем з stdlib і тесты Worker біжать проти in-memory хранилища.

### Наставлїня

```bash
# pipeline
python3 -m pytest pipeline/tests/          # мало бы быти вшытко зелене, без потреби іншталації pip

# worker
cd worker && npm install
npm run typecheck && npm test              # tsc --noEmit + vitest
npm run dev                                # localhost:8787
```

### Де поміч найвеце хосенна

**i18n / локалізація** — `worker/src/i18n/ui-strings.json` є жрідлом текстів інтерфейсу. Рецензія од носителя языка будькоторой неанґліцькой локалі є высокоцінна: найти незґрабны машиновы выступы, справити проблемы з RTL/росположеньом, поліпшити крайны случаи догваряня языка.

**Якость OCR** — ліпша перед-обробка старых машынописных сканів перед OCR; тестовый інштрументарій порівнуючій опен-сорс енджін з резервным Tesseract на взірцёвых сторінках.

**Доступность** — аудіт рендерованых сторінок (`worker/src/render/`) проти WCAG; CSP є строгый (без `unsafe-inline`), зато рішіня мусять фунґовати в рамках того.

**Ерґономія API** — `worker/src/routes/` — сторінкованя, філтрованя, опис OpenAPI, приміры клієнтів.

**Надіяность пайплайну** — веце шляхів ґраціозной деґрадації, ліпше звітованя о поступі, крайны случаи детекції делта (`pipeline/lib/delta.py`).

**Документація** — `docs/20260511/` (繁體中文; `00-*` є індекс). Переклады проєктной документації до анґлічтіны суть витаны.

### Основны правила

- Вшыткы шляхи релатівны — проект мусить быти переносимый меджі компютерами. Жадны твердокодованы абсолутны шляхи.
- Не додавайте залежность `pip` до *основного* модулу пайплайну. Опціоналны етапы можуть хосновати опціоналны пакеты, але мусять ґраціозно деґрадовати без них.
- Не ослаблюйте ставовый автомат, што йде лем допереду — то є строп расходов.
- Не додавайте офіціалны інсіґнії влады США, і не додавайте нич, што бы одкрыло жрідловы зачорнены части.
- Зміны схемы D1 дотыкають ся **двох** файлів: `pipeline/lib/manifest_schema.sql` і `db/schema.sql`.
- Тесты з новым кодом. Conventional-commit повідомлїня.
