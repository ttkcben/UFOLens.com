## ufolens.com — многоязычна, выгледовательна платформа про архів PURSUE UAP

**Нажыво:** https://www.ufolens.com  ·  **API:** https://www.ufolens.com/api/v1  ·  **Жрідловый архів:** https://www.war.gov/ufo

`ufolens.com` републікує архів **PURSUE** одтаємненых записів UAP / UFO Міністерства обороны США як зналостну платформу: повнотекстове выгледованя, машиновый переклад цілого корпусу, презераня мап і часовых осїй, і публичный JSON API. Жрідловы документы суть творами федералной влады США і в рамках США суть публичным маєтком ([17 U.S.C. §105](https://www.copyright.gov/title17/92chap1.html#105)). Тот проект **не є афіліованый з владов США**, не хоснує офіціалны інсіґнії і ниґда не одкрывать зачорнены части.

### Архітектура

```
Локалный компютер (Apple Silicon, домашнїй IP)    Edge сіть
─────────────────────────────────────────           ─────────────────────────
pipeline/  (Python 3.10, ядро лем з stdlib)         worker/  (TypeScript, Hono.js)
  fetch → OCR → translate → publish  (лем допереду)   /{lang}/...   сторінкы
  OCR: опен-сорс енджін (Tesseract CLI як резерва)    /api/v1/...   публичный API
  translate / NER: локалный LLM (Gemma через Ollama) /admin        конзола оператора
  стан: SQLite маніфест                            опертый на: edge SQL DB, обєктове
        │                                              хранилище (жрідловы PDF), KV кеш
        └── публікує пакет: SQL + маніфест активів + список для вымазаня з кешу ──┘
```

- **Нульовы расходы на хмарову AI за каждый документ.** OCR і переклад біжать локално; ставовый автомат, што йде лем допереду (`discovered → downloaded → ocr_done → translated → published`), ґарантує, же жаден документ не буде переобробленый, хіба же ся змінить.
- **Ядро пайплайну не має жадных залежностей од третїх сторін** — модулі про парсованя / маніфест / делта біжать і тестують ся на чистім Python без жадных іншталацій через pip; етапы OCR/перекладу ґраціозно деґрадують, кідь опціоналны пакеты хыбують.
- **Edge сайт** аплікує строгы безпечностны гедеры + CSP (без `unsafe-inline`; вбудованый JSON-LD запіненый через sha256), догваряня языка через `Accept-Language` + мапованя країн, 30-деновый KV кеш сторінок і штоденный cron на утримованя порядку.
- **Інкременталны оновлїня:** детектор делта порівнує жрідловый індекс і передає до пайплайну лем зміны.

### Про девелоперів

Публичный API на https://www.ufolens.com/api/v1 вертать документы і метаданы як JSON. Анонімный приступ є обмедженый по частотї; пожадайте о ключ про рівнї дослідника/девелопера. Позерайте секцію API на сайті про ендпоінты і ліміты.

Код завершеный; сайт розгорнутый на https://www.ufolens.com. Продукчна база даных є наповнена запущіням офлайн пайплайну і публікаціов пакету допереду (`cli_publish run --remote`). Повна проєктна документація находить ся в `docs/20260511/`.
