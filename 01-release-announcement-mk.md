## ufolens.com — повеќејазична, пребарлива платформа за архивата PURSUE UAP

**Во живо:** https://www.ufolens.com · **API:** https://www.ufolens.com/api/v1 · **Изворна архива:** https://www.war.gov/ufo

`ufolens.com` ја реобјавува архивата **PURSUE** на американското воено министерство со декласифицирани записи за UAP / UFO како платформа за знаење: пребарување на целосен текст, машински превод низ целиот корпус, истражување преку мапа и временска линија, и јавен JSON API. Изворните документи се дела на федералната влада на САД и во САД се во јавна сопственост ([17 U.S.C. §105](https://www.copyright.gov/title17/92chap1.html#105)). Овој проект **не е поврзан со владата на САД**, не користи официјални ознаки и никогаш не ги поништува редакциите.

### Архитектура

```
Локална машина (Apple Silicon, домашна IP)           Рабна мрежа
─────────────────────────────────────────           ─────────────────────────
pipeline/  (Python 3.10, јадро само со stdlib)       worker/  (TypeScript, Hono.js)
  преземи → OCR → преведи → објави (само напред)        /{lang}/...   страници
  OCR: мотор со отворен код (Tesseract CLI како резерва) /api/v1/...   јавен API
  превод / NER: локален LLM (Gemma преку Ollama)        /admin        операторска конзола
  состојба: SQLite манифест                           поддржано од: рабна SQL база на податоци,
        │                                              објектно складирање (изворни PDF-ови), KV кеш
        └── објавува пакет: SQL + манифест на средства + листа за чистење на кеш ──┘
```

- **Нула трошоци за облак-AI по документ.** OCR и преводот се извршуваат локално; состојбената машина само за напред (`откриен → преземен → ocr_завршен → преведен → објавен`) гарантира дека ниеден документ не се репроцесира освен ако не е променет.
- **Јадрото на патеката за обработка нема зависности од трети страни** — модулите за парсирање / манифест / делта работат и се тестираат на чист Python без ништо инсталирано преку pip; фазите на OCR/превод грациозно се деградираат кога опционалните пакети се отсутни.
- **Рабната страница** применува строги безбедносни заглавија + CSP (без `unsafe-inline`; вметнатиот JSON-LD е sha256-закачен), договарање на јазик преку `Accept-Language` + мапирање на земји, 30-дневен KV кеш за страници и дневен cron за одржување.
- **Инкрементални ажурирања:** детектор на делта го споредува изворниот индекс и ги внесува само промените назад во патеката за обработка.

### За програмери

Јавниот API на https://www.ufolens.com/api/v1 враќа документи и метаподатоци како JSON. Анонимниот пристап е со ограничена стапка; побарајте клуч за истражувачки/програмерски нивоа. Погледнете го делот за API на страницата за крајни точки и ограничувања.

### Статус

Кодот е комплетен; страницата е распоредена на https://www.ufolens.com. Продукциската база на податоци се пополнува со извршување на офлајн патеката за обработка и објавување на пакетот напред (`cli_publish run --remote`). Целосните дизајн документи се наоѓаат во `docs/20260511/`.
