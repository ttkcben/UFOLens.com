## Придонесување за ufolens.com

[ufolens.com](https://www.ufolens.com) ја претвора [PURSUE UAP архивата](https://www.war.gov/ufo) на американското воено министерство во пребарлива, повеќејазична платформа со [јавен API](https://www.ufolens.com/api/v1). Се состои од две половини — локална патека за внесување во Python (`pipeline/`) и рабна апликација во TypeScript/Hono (`worker/`) — кои се среќаваат на еден интерфејс: објавен пакет со SQL и средства.

Не ви се потребни никакви облак акредитиви за да придонесете. Јадрените модули на патеката за обработка се само со stdlib, а тестовите на Worker-от се извршуваат против мемориско складирање.

### Поставување

```bash
# pipeline
python3 -m pytest pipeline/tests/          # треба сите да бидат зелени, не е потребна pip инсталација

# worker
cd worker && npm install
npm run typecheck && npm test              # tsc --noEmit + vitest
npm run dev                                # localhost:8787
```

### Каде помошта е најкорисна

**i18n / локализација** — `worker/src/i18n/ui-strings.json` е изворот на стринговите за корисничкиот интерфејс. Преглед од мајчин говорник на кој било не-англиски јазик е од голема вредност: откривање на несмасни машински преводи, поправка на проблеми со RTL/распоред, подобрување на гранични случаи при договарање на јазик.

**Квалитет на OCR** — подобро препроцесирање на стари скенирани документи пишувани на машина за пишување пред OCR; рамка за евалуација што го споредува моторот со отворен код со резервниот Tesseract на примероци од страници.

**Пристапност** — ревизија на рендерираните страници (`worker/src/render/`) според WCAG; CSP е строг (без `unsafe-inline`), па решенијата мора да работат во рамките на тоа.

**Ергономија на API** — `worker/src/routes/` — пагинација, филтрирање, OpenAPI опис, пример-клиенти.

**Робусност на патеката за обработка** — повеќе патеки за грациозна деградација, подобро известување за напредокот, гранични случаи при детекција на делта (`pipeline/lib/delta.py`).

**Документација** — `docs/20260511/` (繁體中文; `00-*` е индексот). Преводите на дизајн документите на англиски се добредојдени.

### Основни правила

- Сите патеки се релативни — проектот мора да биде пренослив меѓу машини. Нема хардкодирани апсолутни патеки.
- Не додавајте pip зависност на *јадрен* модул од патеката за обработка. Опционалните фази може да користат опционални пакети, и мора грациозно да се деградираат без нив.
- Не ја ослабувајте состојбената машина само за напред — тоа е таванот на трошоците.
- Не воведувајте официјални ознаки на владата на САД, и не додавајте ништо што ги поништува изворните редакции.
- Промените во D1 шемата допираат **две** датотеки: `pipeline/lib/manifest_schema.sql` и `db/schema.sql`.
- Тестови со новиот код. Пораки за commit според Conventional Commits.
